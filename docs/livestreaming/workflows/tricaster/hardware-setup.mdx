# Setting up the TC Mini X hardware

We are assuming you are starting with the TriCaster system in its padded suitcase.

## Things you need

#### Required

- The TriCaster system in its padded suitcase. The suitcase should have the following:
  - A desktop PC tower
  - A computer mouse
  - A computer keyboard
  - [A TriCaster Mini Control Surface](../../reference/tricaster/control-surface.md)
- Computer monitor that accepts DisplayPort (not included in the TriCaster system; HDMI is not supported)
- RJ45 networking cable (to connect the TriCaster to the Internet via Ethernet)
  - Therefore, you will need to set up the TriCaster system indoors, located near an Ethernet wall outlet
- Wired headphones or speakers (optional; useful if you wish to monitor the stream audio)
  - You may need a 6.35 mm to 3.5 mm audio adaptor because the TriCaster only has ports for 6.35 mm audio connectors, and your audio devices probably use 3.5 mm audio connectors.
- A camera that can output through HDMI or NDI
  - Webcams are not natively supported in the TriCaster system (they work occasionally, but this should not be relied upon)

#### Optional

- A table
- A chair to sit on
- If you wish to use LivePanel:tm: in a wired private network:
  - Two additional RJ45 networking cable
  - An Ethernet switch
  - Another device that can connect to Ethernet (e.g. a laptop or an iPad with an Ethernet to USB-C adaptor)
- If you wish to use LivePanel:tm: in a wired private network:
  - An additional RJ45 networking cable
  - An Internet router
  - Another device that can connect to a wireless network (e.g. a laptop, an iPad, a phone)
- If you have commentators:
  - A microphone
  - An additional camera
  - Green screen
