# Livestreaming using LSMSA's TC Mini X system

The TriCaster system is a powerful, professional system for livestreaming events. It consists of a dedicated computer system that can be transported in a padded suitcase. However, the TriCaster system does NOT include a monitor or a way to connect to the Internet wirelessly, so you will need to plan for this.

:::info

In the future, LSMSA's TriCaster system may have a permanent home in the new broadcasting room located in the Gym/SAC. In that case, you don't need to complete the hardware setup.

:::
