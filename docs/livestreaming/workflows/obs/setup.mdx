# Setting up OBS Studio

After you install OBS Studio, you will need to complete these steps the first time you use OBS Studio. Otherwise, the software won't be properly set up for livestreaming!

## 1: Configure using the Auto-Configuration Wizard

1. Open up OBS Studio

2. If this is your first time opening OBS Studio, you should see the modal below.  
   :::info
   If you don't see the modal below, go to the menu bar (the horizontal list of words at the very top left of the screen), select `Tools`, then select `Auto-Configuration Wizard`.
   :::

7. Click Next

8. You need to add the stream information, so that OBS Studio knows where to send the stream footage to the destination platform. For instance, you might be streaming to YouTube, Twitch, or Vimeo (you may need to select "Show All..." for this last one).

   - For some platforms (like YouTube and Twitch), you can directly connect an account to stream to. **This requires you to have the login information for that account.**
   - Alternatively, you can provide a stream key. Check out the FAQ page on [Stream Keys](/docs/livestreaming/reference/faq/stream-key.md#how-to-obtain-a-stream-key) to see how to obtain one for your platform, then return here and paste the stream key in the appropriate location (make sure to select the correct platform in the **Service** dropdown in OBS!)

9. Click Next

10. The Wizard should now run bandwidth tests by communicating with the servers of the platform you selected.

    - If you receive an error that says "Failed to connect to any servers, please check your internet connection and
      try again." you should (obviously) check your Internet connection first. If that's fine, the servers for the
      platform might not be up. Or, this is your first time attempting to livestream on a platform, and that platform
      is making you wait some time before you can livestream (for example YouTube makes you wait 24 hours after
      requesting streaming access for the first time).
    - If you receive an error and you want to just finish this step later, do the following:

      1. Click Back
      2. Uncheck the option at the bottom that says "Estimate bitrate with bandwidth test (may take a few minutes)"
      3. Ensure the dropdown entitled **Server** is set to the best option
      4. Click Next

12. If you selected a service like YouTube or Twitch, one or two new dockable panels may appear. This will let you view you livestream's chat, as well as manage your livestream on the platform.

## 2: Scene collection

A scene collection is a group of "scenes", which each define how your livestream will looks and how it works. You can have multiple scenes; for example, one scene can be for the camera pointed at the game, while another scene is for the camera pointed at commentators. You can also have a scene that doesn't have a camera and instead shows text such as "Thanks for watching" or even the game score.

In each scene, there is a list of "input sources", which defines an object that appears in the livestream. This could be a camera source, an image source, a text source, etc.

Because you just installed OBS, you need to set up a scene collection. You can do one of two things here:

- [Option A: Install a scene collection](#option-a-install-a-scene-collection)
- [Option B: Set up a scene collection](#option-b-set-up-a-scene-collection)

### Option A: Install a scene collection

Download and use one of the scene collections we made: <Link href="/docs/livestreaming/reference/assets/obs-scene-collections" target="_blank">OBS Scene Collections</Link>

To do this, follow the steps in <Link href="/docs/livestreaming/reference/obs/scene-collection-installation" target="_blank">Installing a Scene Collection in OBS</Link>
