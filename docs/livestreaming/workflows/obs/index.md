# Livestreaming at LSMSA using OBS Studio

OBS Studio (which stands for "Open Broadcaster Software") is a free, yet powerful software that allows you to create a good-looking livestream. It's a good option if you don't want to use a phone to livestream, yet need something more portable than the TriCaster.

:::info
Currently, OBS can not be installed on school devices, so you will need a personal laptop.
:::
