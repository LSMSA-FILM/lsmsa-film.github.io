# Installing OBS Studio

:::important

You cannot install software onto student laptops! You will need to install OBS Studio onto a personal laptop.

If you wish to get OBS Studio onto a student laptop, contact the [LSMSA IT department](mailto:it@lsmsa.edu)

:::

Follow the steps in include page-ref.md path="docs/livestreaming/obs-reference/installation.md" new-tab=true to get OBS Studio running on your computer. Then, return to this page and continue following these steps.

1. Navigate to the website for OBS Studio: <Link href="https://obsproject.com/" target="_blank">obsproject.com</Link>

2. The homepage of the website should list operating systems (i.e., Windows, Mac, Linux). If it doesn't, go to the top right and navigate to the **Download** page.

3. Select your operating system

4. It should automatically download the appropriate file. If it doesn't, click "Download Installer"

5. After it downloads, open the installer file.

6. Follow the steps in the installer file to install OBS Studio onto your computer.

---

You should now have OBS Studio installed on your computer. Click the Next button below to learn how to set up OBS Studio for livestreaming.
