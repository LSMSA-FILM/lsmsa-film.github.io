# Recommended Workflows

This documentation provides tutorials on setting up and managing livestreaming, as well as resources and reference material to make this process easier.

Look through the tables below and find a goal that looks like what you're trying to do. Then, follow the recommended workflow to learn how to successfully achieve that goal. The tables are sorted into the following categories:

- [Assemblies](#assemblies)
- [Athletics](#athletics)
- [Esports](#esports)
- [Recitals](#recitals)
