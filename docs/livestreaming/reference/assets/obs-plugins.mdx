# Plugins for OBS Studio

import PageStub from "@site/src/components/PageStub";

<PageStub />

This is a list of a few OBS plugins that you may find useful for livestreaming. OBS plugins are additional addons that extend the functionality of OBS and improve the workflow for a task. You should download these at your own risk.

:::info[Can't find the download button to the plugin?]

On the webpage for the plugin, the download button is to the right of the plugin's title.

I'm telling you this because this took me a while to figure out...

:::

## Plugins

### Downstream Keyer

This allows you to have scenes that are always overlaid on top of everything at all times. This is useful for score bar graphics and a logo watermark.

Webpage & Download: [https://obsproject.com/forum/resources/downstream-keyer.1254/](https://obsproject.com/forum/resources/downstream-keyer.1254/)

### TeleScore

This is a separate app that gives a clean interface to update the scoreboard. The scene collection is currently set up to use that. You may need to relink the Text sources after you download Telescore. However, this software is in beta and is rarely updated.

Webpage: [https://obsproject.com/forum/resources/telescore-fully-customizable-open-source-scoreboard-software.1658/](https://obsproject.com/forum/resources/telescore-fully-customizable-open-source-scoreboard-software.1658/%20)  
 Download: [https://github.com/JumpShot-Interactive/TeleScore/releases/latest](https://github.com/JumpShot-Interactive/TeleScore/releases/latest)

### Advanced Scene Switcher

Lets you create macros to automate things in OBS. You will want to find a tutorial on this, or just ignore this one and only use it if you wanna set up a scoreboard and you don’t wanna use TeleScore.

Webpage: [https://obsproject.com/forum/resources/advanced-scene-switcher.395/](https://obsproject.com/forum/resources/advanced-scene-switcher.395/%20)  
 Download: [https://github.com/WarmUpTill/SceneSwitcher/releases/latest](https://github.com/WarmUpTill/SceneSwitcher/releases/latest)

### DistroAV

Remember the acronym NDI. If you know what that is, you can use this plugin. Otherwise, ignore this plugin.

Webpage: [https://obsproject.com/forum/resources/distroav-network-audio-video-in-obs-studio-using-ndi%C2%AE-technology.528/](https://obsproject.com/forum/resources/distroav-network-audio-video-in-obs-studio-using-ndi%C2%AE-technology.528/%20)  
 Download: [https://github.com/DistroAV/DistroAV/releases/latest](https://github.com/DistroAV/DistroAV/releases/latest)

### VDO Ninja

Not a plugin, but a website. Basically lets you use video input from any device; notably, that includes phone cameras. Takes a bit to figure out. Also doesn’t look the best, because what’s doing is streaming your phone camera to their servers, then streaming is back to the computer running OBS. They have tutorials on their website, check it out if you’re interested:

Website: [https://vdo.ninja/](https://vdo.ninja/)
