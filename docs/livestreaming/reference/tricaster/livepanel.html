LivePanel

LivePanel home interface

What is LivePanel?​

LivePanel is a user interface that provides additional useful tools for managing your livestream. It is a webpage that is hosted on the TriCaster system, and can be accessed by connecting to the TriCaster's local network IP address of 192.168.1.10.

Some features of LivePanel include:

  • Scoreboard UI
  • and a lot more that's unimportant right now

Connecting to LivePanel in a private network​

To use LivePanel, you must navigate to the LivePanel webpage. When I say webpage, please note this webpage is not on the Internet; rather, it is being hosted on the TriCaster computer, and you must connect to it by configuring your devices (which this page will teach you how to do).

In addition to the TriCaster, you will need:

  • A laptop or a device
    • You will need administrative permissions on this device, so you cannot use a school laptop (unless you ask the IT department to follow the steps on this page for you)
    • This device needs to be able to connect to Ethernet (using an RJ45 cable). If it doesn't have a port, purchase an adapter such as this one: USB Ethernet Adapter on Amazon
  • A network/Ethernet/RJ45 cable

Then, follow these steps:

  1. Plug in your network cable to the top Ethernet port on the back of the TriCaster

    Why the top port?

    Isaac configured the TriCaster so that the LivePanel webpage is available through the top Ethernet port. Configuring it so LivePanel is available through both ports might interfere with the TriCaster's ability to connect to the Internet, so I did not do this.

    If you do wish to change this for whatever reason, Isaac will update this section with more information later on.

  1. Plug the other end of the network cable to your laptop.

    • If your laptop doesn't have an Ethernet port, connect the cable to the adapter and plug the adapter to the laptop. Most of the time, it should work. But drivers, maybe

  2. Select the operating system of your laptop below and continue from there:

  • Windows
  • Mac

  1. Open the Network Connections settings on your personal laptop.

    • To do this, press Windows key + R, which will open a dialog on the bottom right of your screen. In this dialog, enter this command: 
      ncpa.cpl
      It should look like the image below. Then, hit OK.
      Run window

  2. Locate (but don't click yet) the option that corresponds to your Ethernet. The name of the option is different per device, so you may need to experiment.

  3. On this option, right click it and select Properties (located at the bottom of the list)

  4. In the list that appears, find the option entitled `Internet Protocol Version 4 (TCP/IPv4). It is highlighted in the image below.

    The `Internet Protocol Version 4 (TCP/IPv4)` option is highlighted

  5. A window will appear. Set the settings as follows:

    • Use the following IP address
    • IP address: 192.168.1.20 (the 20 can be any number from 0 to 255, as long as it isn't 10. If you are following this tutorial for multiple devices, each device should have a unique number.)
    • Subnet mask: 255.255.255.0 (or can also be 255.255.0.0)

    The rest of the settings you can leave alone.

  6. The window should look something like this:

    What your network settings should look like

  7. Click OK and close all the windows you just opened

  8. Placeholder step so that this has the same number of steps as the Mac lol

  1. Open the System Settings app

  2. Navigate to the Network tab on the left sidebar

  3. Find the item labeled Ethernet (if your device has a built-in Ethernet port) or an option that should correspond to your Ethernet adapter.

    • If you don't know which item it is, wait a few moments and one of the items (besides Wi-Fi) might show as "Connected"; select this one. Otherwise, follow the next steps for each item to figure out which one corresponds to your Ethernet adapter.

  4. Click on that item. Then, near the top right, click "Details...""

  5. A modal should appear. On the sidebar of that modal, select "TCP/IP"

  6. Set the settings as follows:

    • Configure IPv4: Manually
    • IP address: 192.168.1.20 (the 20 can be any number from 0 to 255, as long as it isn't 10. If you are following this tutorial for multiple devices, each device should have a unique number.)
    • Subnet mask: 255.255.255.0 (or can also be 255.255.0.0)
    Settings for configuring IP address

  7. Click OK

  8. The info box should look something like this:

    What your network settings should look like

  1. On the TriCaster, make sure it is open to a live production. You should see something like the image below (insert image from user manual)

  2. Now, open any web browser and enter the following into the webpage locator bar: 192.168.1.10

  3. If you configured everything correctly, you will be prompted with an authentication popup that asks for a username and password. If you were not provided with these, try the default:

    • Username: admin
    • Password: admin

  4. You should now have access to the LivePanel interface.
