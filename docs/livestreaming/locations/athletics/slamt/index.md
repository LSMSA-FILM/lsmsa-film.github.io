SLAMT is a yearly athletics event, where LSMSA teams up with its nearby sister schools to have a friendly competition. As it is a large event and has many people traveling to participate, it may be useful to livestream the event.

Games are typically played in one of the following locations:

1. **LSMSA Gym**: basketball, volleyball, hype events, etc.
   - How to livestream here: [Home Games (gym)](../home-games-gym/index.md)
2. **President's Field (located by Chaplin's Lake)**: soccer, flag football, ultimate frisbee, etc.
   - How to livestream here: [Home Games (outdoors)](../home-games-outdoor/index.md)
3. **LSMSA CPT lobby**: table tennis, etc.
   - How to livestream here: [CPT Lobby](./cpt-lobby.md)
