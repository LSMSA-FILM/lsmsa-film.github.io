At LSMSA, the method used to livestream typically depends on the type of event. There are three methods that are typically used:
1. LSMSA's TriCaster (TC Mini X) system
2. OBS Studio on a student's personal computer
3. A livestream broadcaster box, such as LSMSA's Teradek Vidiu Go
This page will list the pros and cons of each method, as well as provide a brief overview on what each method entails
# LSMSA's TriCaster (TC Mini X) system
Often referred to as just the "TriCaster", this system consists of a **small desktop computer** purpose-built for livestreaming. The TriCaster runs on Windows 11 as well as custom TriCaster software that comes with the computer. The TriCaster comes with a **keyboard**, **mouse**, and a **TriCaster Mini Control Surface**, all of which plug into the computer via USB. The TriCaster is somewhat portable, as can easily be packed into a large, padded box that has space for all of the aforementioned hardware.

In order to run, the computer needs to be plugged into a display (via its four Mini DisplayPort ports) and—optionally—a speaker setup connected to the **audio out jack** on the front of the computer. Additionally, the computer does NOT support Wi-Fi, meaning that to connect to the Internet (required for livestreaming), you need to plug an Ethernet cable into one of the **two Ethernet ports** located on the back of the computer. The other Ethernet port can be used to connect to a private network that allows other devices to access the TriCaster's LivePanel system (described in [[Using LivePanel in a private network]])

For more information about the TriCaster, see [[4 TriCaster Reference|TriCaster Reference]]

## Pros
- Allows for the creation of advanced and professional-looking livestreams
- Especially good at livestreams that require multiple cameras or scenes
- Once it is set up, it can be set up so that an inexperienced person can moderate the livestream and transition between different cameras

## Cons
- Highest learning curve, requires you to learn how to use the system several weeks in advance
